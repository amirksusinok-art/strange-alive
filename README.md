# STRANGE — Сайт, который живёт

Маленькое цифровое существо, которое замечает курсор, реагирует на заботу, меняет настроение и постепенно раскрывает свои секреты.

## Запуск

Нужен Node.js 20 или новее. Зависимости для игры не требуются.

```sh
npm run dev
```

Открыть http://127.0.0.1:4173. Для статической публикации:

```sh
npm run build
```

Результат — папка `dist/`. Её содержимое можно разместить на любом статическом хостинге. Настройки Render описаны в `render.yaml`.

## Что умеет существо

- Следит глазами за курсором, моргает и реагирует на прикосновения.
- Пять параметров: настроение, доверие, голод, скука и злость.
- Четыре действия заботы, возможность помолчать, реакции на повторные клики и бездействие.
- Записки, танцующие кнопки, временные подписи и секретная сцена.
- Три формы развития; знакомство сохраняется в браузере.
- Звук включается пользователем. Поддерживаются клавиатура, мобильный экран и системное уменьшение движения.

Первый секрет требует минимум трёх минут видимого времени, доверия от 60 и всех четырёх разных действий. Второй форме нужны доверие от 40 и две встречи, третьей — доверие от 75 и три встречи. Новая встреча для роста засчитывается через 30 минут. Быстрые перезагрузки и повторение одной кнопки не ускоряют рост.

Пока страница закрыта или вкладка скрыта, параметры не ухудшаются. Переноса истории между браузерами нет. Если сохранение запрещено браузером, игра работает до закрытия страницы и показывает уведомление. Сброс истории — в настройках с подтверждением.

## Проверка

```sh
npm test
npm run build
```

Автоматическая проверка браузера (дополнительный инструмент разработки):

```sh
npm install --no-save playwright
npm run dev
# В другом терминале:
npm run test:browser
```

Требуется установленный Google Chrome. Можно указать `PLAYWRIGHT_MODULE` как путь/URL к уже установленному пакету Playwright. Скриншоты и результаты появляются в `.qa/` и не публикуются. `SITE_URL` позволяет проверить опубликованную версию вместо локальной.

## Устройство

- `public/state.js` — состояние, переходы, сохранение и развитие.
- `public/script.js` — действия, таймеры, диалоги, звук и события.
- `public/style.css` — адаптивный интерфейс и процедурный персонаж.
- `tests/state.test.js` — проверки игровых правил и восстановления данных.
- `scripts/` — локальный сервер, сборка и проверка браузера.
